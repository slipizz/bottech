# Telegram бот техподдержки с AI

Бот принимает сообщения пользователей в личке и создает **отдельный топик** в support-форуме (Telegram supergroup with topics) для каждого пользователя.

## Возможности

- Создание отдельного топика на каждого пользователя.
- Пересылка сообщений между пользователем и командой поддержки.
- Поддержка любых типов контента (текст, фото, документы, аудио, видео, файлы) через `copyMessage`.
- Команда `/ai` для ответа от LLM (OpenAI-совместимый API).

## Требования

- Python 3.10+
- Telegram бот (токен от @BotFather)
- Супергруппа с включенными Topics (Forum), куда добавлен бот-админ

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните .env
python bot.py
```

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота
- `SUPPORT_CHAT_ID` — ID форума поддержки (например `-1001234567890`)
- `AI_ENABLED` — `true/false`
- `AI_API_KEY` — ключ AI-провайдера
- `AI_MODEL` — модель (по умолчанию `gpt-4o-mini`)
- `AI_BASE_URL` — optional base url для OpenAI-compatible API

## Поток работы

1. Пользователь пишет боту в ЛС.
2. Бот создает топик (если еще не создан) в support-чате.
3. Сообщение копируется в нужный топик.
4. Оператор отвечает в этом топике, бот копирует ответ пользователю в ЛС.

## Важно

- У бота должны быть права администратора в support-группе.
- Пользователь должен хотя бы раз начать диалог с ботом (иначе бот не сможет писать первым).
